09 — FAQ

Perguntas frequentes.

Algumas respostas rápidas para dúvidas comuns sobre o projeto.

O questionário identifica se estou sofrendo violência? +

Não. Ele é uma ferramenta educativa de reflexão e não substitui avaliação profissional ou atendimento especializado.

O site sabe minha localização? +

Não automaticamente. A busca de localização funciona somente quando você digita uma cidade, bairro ou CEP.

O plano de segurança é enviado para alguém? +

Não. Nesta versão, as informações ficam armazenadas localmente no navegador.

O modo discreto apaga meu histórico? +

Não. O modo discreto altera a aparência do site, mas não apaga automaticamente histórico, downloads ou registros do navegador.

Posso usar o site para ajudar outra pessoa? +

Sim. A seção "Como ajudar" apresenta orientações gerais para oferecer apoio de maneira respeitosa.
